# Vue Fashion

Адаптивный фронтенд-проект на Vue 3 + Vite, сверстанный по Figma-макету (desktop / tablet / iPhone), включая hover-состояния и подключенные изображения из макета.

## Стек

- Vue 3
- Vite
- CSS
- Docker + Nginx

## Запуск локально

```bash
npm install
npm run dev
```

## Docker

```bash
docker compose up -d --build
```
